# Инвиз

Нативное плавающее приложение macOS для работы с Codex через авторизацию приложения ChatGPT и подписку пользователя.

## Возможности

- Модели и уровни reasoning загружаются из каталога текущего аккаунта ChatGPT.
- App Server передаёт ответы и ход работы по мере генерации, поддерживает отдельные переписки и историю Codex.
- Вопросы Codex и запросы на подтверждение показываются внутри чата.
- Последняя рабочая папка, выбранная модель и уровень усилий запоминаются.
- Отображаются текущие 5-часовое и недельное окна использования Codex, полученные от аккаунта.
- Окно поверх других окон и настроено на исключение из захвата экрана; приложение работает без значка в Dock.
- Доступ к файлам и разрешения запуска команд совпадают с текущей конфигурацией Codex: `danger-full-access` и `never`.

## Сборка и установка

Нужны macOS 13+, Xcode Command Line Tools и ChatGPT для macOS с выполненным входом.

```sh
./build-app.sh
```

Скрипт собирает версию из `VERSION`, устанавливает `~/Applications/Инвиз.app` и запускает приложение. Открыть его снова можно через Spotlight по слову «Инвиз».

## Версии и публикация

Для небольшого исправления, новой функции или крупного релиза используется соответственно patch, minor или major:

```sh
./release.sh patch "Исправление курсора"
./release.sh minor "Сохранение чатов"
./release.sh major "Новый интерфейс и App Server"
```

Скрипт увеличивает `VERSION`, собирает приложение, создаёт commit и Git tag, отправляет их в приватный репозиторий GitHub и публикует macOS архив релиза.
